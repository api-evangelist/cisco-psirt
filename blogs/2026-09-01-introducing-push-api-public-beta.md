We’re excited to announce the public beta of Push API , an event-driven alternative to repeatedly polling the Meraki Dashboard API. API rate limits can make frequent polling difficult to scale, especially as network environments grow. Push API enables you to subscribe to supported topics and receive near-real-time updates through webhooks - helping reduce polling volume and preserve API capacity for other operational needs.
